# 示例数据

`fictional-students-180.csv` 是自动化验收专用的虚构名单，不含任何真实学生信息：

- 共 180 人，学号统一以 `TEST2026` 开头；
- 建筑学、城乡规划、风景园林各 60 人；
- 只提供“学号、姓名、专业”三列，因此它不是可直接导入生产的名单；测试会在内存中补入确定性的虚构校务证件号，并取末 6 位作为激活码；
- 可用于关闭状态下的自动化测试，不得导入正在使用的正式活动，也不得替代权威名单模板。

配套回归见 `tests/test_fictional_roster_flow.py`。测试会验证批量导入、180 个确定性虚构激活码、
同一出口 IP 并发登录、原子抢位、结果导出、活动归档及旧会话失效。
